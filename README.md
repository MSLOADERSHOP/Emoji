# TikTok Verified Custom Badge — WM Keyboard Add-on

This repository provides:
1. **TikTok Verified Emoji Font** — a custom TTF using private-use code point U+E000. This is not a standard Unicode emoji; test rendering on-device.
2. **TikTok Verified Badge** — a searchable image sticker based on the supplied `verified.svg`. It is an image/sticker, not inline Unicode text.

## Install
In WM Keyboard, open Add-ons → Add repository and paste this repository's GitHub URL after uploading these files to a public repository.

Required root file: `wmkeyboard-repo.json`.
